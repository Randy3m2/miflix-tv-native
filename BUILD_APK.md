# MiFlix TV Native 2.0 Alpha 1.1

This build keeps the project on Android API 36 / Android Gradle Plugin 8.13.2 and pins Compose/Coil to compatible versions.

Required GitHub repository secrets:
- `MIFLIX_TMDB_TOKEN`
- `MIFLIX_TORRENTIO_MANIFEST`

Run **Actions > Build MiFlix Native TV APK > Run workflow**.

Expected output:
- `MiFlix-TV-Native-v2.0.0-alpha1.1.apk`
- release tag `native-v2.0.0-alpha1.1`
