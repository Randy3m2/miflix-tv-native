# BruniO PC Windows RC1

Añade **desktop/brunio-pc/** y **.github/workflows/build-pc.yml** al repositorio existente, sin reemplazar Android.

Luego: Actions → Build BruniO PC Windows → Run workflow → descarga BruniO-PC-Setup-1.0.0-rc1.exe.

Guía completa: desktop/brunio-pc/README.md. Este archivo es el proyecto; el .exe se genera en Windows mediante el workflow. No necesita SQL nuevo ni alterar la versión TV.
