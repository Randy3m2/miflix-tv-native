# Manual playback links

Focus Play/Continue or an episode card/row. Hold OK/Enter or the remote Play
button for one second to list all distinct playable HTTP links returned by the
configured add-ons. Select a link to play it. Short press keeps quick play.
The long-press release is consumed, so it cannot also start quick play.
Back/Close cancels selection. Subtitle loading is preserved for the chosen link.

Includes the previous RC1 compilation fixes, disappearing player overlays and
keep-screen-on during active playback. Permanent APK URL is unchanged.

Source checks completed. Android compilation and remote/TV verification remain
pending in GitHub Actions and on the device.
