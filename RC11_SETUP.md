# BruniO TV Native RC11

Proyecto completo, acumulativo. Incluye la corrección de Home de RC10.

El botón nativo de Play/Pausa del reproductor muestra fondo blanco sólido e icono casi negro al recibir foco o pasar el puntero. En estado normal mantiene fondo oscuro e icono blanco. Se conserva la acción de Media3, el control remoto y la sincronización de Watch Party.

Reemplaza los archivos en GitHub y ejecuta Build MiFlix Native TV APK. No hay SQL adicional, cambios de Pages/Trakt ni cambios en el código de Downloader.

Se comprobaron sintaxis y recursos. No se compiló el APK ni se verificó el contraste en una TV en este entorno. Después de instalar: pausa → muestra controles → enfoca Play → comprueba el fondo blanco y la reanudación.
